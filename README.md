# TimeDeck by DocFila: desktop releases

Installers for TimeDeck by DocFila, the stage timer that runs a venue host offline from one computer and puts a
full-screen output on every attached display. The app checks this repository's releases for updates.

- Website and help: https://timedeck.docfila.com
- Support: support@docfila.com

Downloads appear under [Releases](../../releases) once a signed build is published. The source lives in DocFila's
main repository; this one holds release files only.
